# v0.1.0-rc.1

校园信息检索 / explainable RAG MVP 的上线候选说明。这是仓库里的 release note，不是 git tag，也不是 GitHub Release。

日期：2026-10-15。验收细节在 `docs/release-acceptance-report.md`。

## 完成能力

- 默认检索策略保持 `hybrid`。`rerank` 默认关闭。默认回答是 `extractive`。
- 前端通过 `/api/search` 展示回答、来源、证据、空结果和错误态。
- 官方摄取覆盖 `tjcu-main-notices`、`tjcu-library`、`tjcu-academic-affairs`、`tjcu-undergrad-admissions`。
- 后台可以登录、查看来源健康、禁用或启用源、手动入队、处理 feedback，并区分社区审核状态。
- 本地 Postgres 上的 `/health`、`/metrics.persistent`、telemetry 和备份恢复演练可以复跑。

## 本次验收里修掉的问题

- 主站通知页现在使用 `#vsb_content_4` 和 `.v_news_content`。旧选择器会把 8 篇通知全部判成没有正文。
- 后台保存来源、feedback 或社区审核后，成功提示不再被同一次刷新清掉。失败也会显示接口返回的消息。
